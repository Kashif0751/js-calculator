# JavaScript Calculator

A command-line calculator built with JavaScript and Node.js.

## Features
- Add, subtract, multiply, divide, remainder, and power
- Handles division by zero
- Checks for invalid input (like letters instead of numbers)
- Repeats until you type `q`

## How to run
1. Install Node.js
2. Run `npm install`
3. Run `node calculator.js`
